### 3.1 职责分权（不变）

| 端 | 职责 | 不做 |

| C3 | 横向/纵向执行、安全门禁、变道执行反馈、遥测广播 | 不猜导航意图 |

### 3.3 端到端链路（按实测修正）

```
高德广播(无 KEY_TYPE 分流, navValid 恒真)
   → 车机车道/限速/TBT 解码
   → 侧向门禁：实线 → BSD → 激光盲区 → D_safe=max(10, v/3.6*2.0)
   → LANECHANGE(seq, direction, param)
C3 侧：
   → app_ip 白名单 + 序号单调校验
   → 0.2s 接受窗内：lane_change_available && !side_object_detected && behind_ttc 达标
   → 通过则进入 laneChangeStarting，否则静默丢弃（无回执）
   → atc_state(=laneChangeState) 回播 0/1/2/3
车机侧：
   → atc_state==3 立即当"完成"，播完成音，进 20s 冷却
```

## 6. 关键任务改法（文件级）

### T-04 · SPEED_LIMIT 载体（P0）

**根因**：`sendControlCommand` 只有一个 `LaneAction` 参数位，`SPEED_LIMIT` 只能塞 `"KEEP"`。

**首选（C3 侧一行，兼容旧车机）**：[amap_navi.py:1034](file:///E:/code/openpilot-ck89757/selfdrive/carrot/amap_navi.py#L1034)

```python
if "cmd" in json_obj:
    c = json_obj.get("cmd")
    self.shared_data.remote_cmd = "CANCEL" if c == "CANCEL_LANE_CHANGE" else c
    if c == "SPEED_LIMIT":
        # 速度数值优先取 v_cruise，其次取 arg；绝不把车道码当速度
        self.shared_data.remote_arg = str(json_obj.get("v_cruise", json_obj.get("arg", "")))
    else:
        self.shared_data.remote_arg = json_obj.get("direction") or json_obj.get("arg")
```

**次选（车机侧）**：为 `SPEED_LIMIT` 增加独立重载，`arg` 直接放速度数字。

**验收**：车机下发 `SPEED_LIMIT/100` → C3 日志 `[SPEED_LIMIT] accepted, nRoadLimitSpeed=100`；随后 `desire_speed = min(v_cruise, nRoadLimitSpeed, atc_desired)` 生效。

> 注意语义：`nRoadLimitSpeed` 是**上限**而非设定值；仅当 `v_cruise > 100` 时才降速。匝道恢复依赖 [carrot_serv.py:1399-1401](file:///E:/code/openpilot-ck89757/selfdrive/carrot/carrot_serv.py#L1399-L1401) 的自动回填，需一并验证。

### T-05 · 车机 fail-closed（P0）

[CarrotTelemetryParser.kt:48-53](file:///E:/汽车/库斯途升级破解/AmapNavi-Reborn/app/src/main/java/tech/touka/amapnavi/data/udp/CarrotTelemetryParser.kt#L48-L50) 改为：缺键或非法值 → `0f`（视为 0 距离，必阻断），不再返回 999。

```kotlin
private fun parseDistanceMeter(rawVal: Float): Float {
    if (rawVal <= -999000.0f) return 0.0f   // 无数据 → 0 → 阻断
    return Math.abs(rawVal)
}
```

同时 `LateralSafetyEvaluator` 增加"无数据即否决"分支，并改用 `ttc_status`（T-09）。

### T-09 · 消费 `ttc_status`

车机门禁顺序改为：`ttc_status != 0 → 阻断（原因码 REJ_TTC_UNKNOWN）`；`== 0` 时才比较 `lidar_behind_vdist_time` 与档位阈值（阈值随 `param` 档位 1.8/2.5/3.5 同步，与 C3 一致）。

### T-08 · 终态回执

C3 在 `desire_helper` 的状态跃迁点写入 `shared_data.lane_change_status`：
- 进入 `preLaneChange` → 1；`laneChangeStarting` → 2；`laneChangeFinishing` → 3；
- `rear_conflict` 触发 → 4；`is_solid` → 5；`side_object_detected`/BSD → 6；状态不满足 → 7；CANCEL/驾驶员覆盖 → 8。

车机侧把 `4~8` 全部映射为"未执行 + 原因"，禁止出现 `LANE_CHANGE_OK`。

### T-13 · 序号隔离

`carrot_serv.carrotCmdIndex` 由内部 DISPLAY 使用；车机遥控序号改走独立字段 `remoteCmdIndex`，`_update_cmd` 只比较 `remoteCmdIndex`。避免 `+=100` 与 `seq` 互相踩踏。

### 10.3 实车顺序

1. 上电：无 torque 报错、8088 不暴露。
2. 高速直线：遥测 10Hz（或 20Hz 若改契约），`ttc_status=1` 且车机不误报。

7. 匝道：500m 起降至 60，减速度 ≤1.0 m/s²；驶离恢复基线（验证 T-04 的恢复路径）。
