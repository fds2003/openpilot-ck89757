## 五、USB 接口硬件模式深度解密与免联网直连方案

### 5.1 为什么之前双 USB-A 线连不上？
- **芯片控制器检测证据**：底层总线为 ChipIdea HDRC (`ci_hdrc.0`)，直接挂接在 `2184000.usb`。
- **寄存器状态**：`cat /sys/.../ci_hdrc.0/inputs/usb_id` 读取值为 **`0`**。
- **电气硬件真相**：在 USB OTG 规范中，`usb_id == 0` 代表车机主板将 ID 引脚**物理永久接地**，强制锁死在 **Host 模式（主机端）**。前排面板的 USB-A 接口因此专门用于对外输出 5V 供电并读取外接 U 盘。若用双公头线连接电脑，双方都是主机，谁都不会识别谁。

### 5.2 如何实现【开机免联网、自动连电脑】？（终极方案）
与其每次手动打开 WiFi ADB 应用，或者去改动 USB 物理从机电路，**最优雅、最稳定、真正的车规级做法是将 WiFi ADB 写入系统开机脚本**：

在车机开机自启脚本 `/system/bin/yantu.sh` 中追加启动指令：
```bash
# 自动在开机时静默激活网络 ADB 5555 端口
setprop service.adb.tcp.port 5555
stop adbd
start adbd
```

**效果**：
只要车机通电开机，车机**自动无感在后台开启 5555 调试端口**！手机热点一开，电脑在任何时候直接输入 `adb connect 车机IP:5555`，不需要在车机屏幕上做任何点击，秒连系统！
