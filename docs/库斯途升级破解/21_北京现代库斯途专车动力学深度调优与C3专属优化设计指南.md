## 一、北京现代库斯途车型机械与物理特征全景透视

北京现代库斯途是现代汽车针对中国家庭与商务市场开发的专属中大型 7 座 MPV。其动力学响应与常见紧凑型轿车（如伊兰特、思域）或小型 SUV 存在**本质的物理级差异**：

```
                      【现代库斯途整车动力学几何图示】
  ◄─────────────────────────── 全长 4,950 mm ───────────────────────────►
 ┌────────────────────────────────────────────────────────────────────────┐
 │   引擎盖 (1.5T/2.0T)   │  前排驾驶舱  │   二排航空座椅   │  三排与后备箱 │
 └───────────┬────────────┴──────┬───────┴──────────┬───────┴──────┬──────┘
             │                   │                  │              │
        前轮转向轴               │             质心 (CG)        后轮轴
       (前麦弗逊独立)            │                              (后扭力梁)
             ▲                   │                  ▲              ▲
             │                   │                  │              │
             └───────────────────┼──────────────────┴──────────────┘
                         超长轴距: 3,055 mm (大轿车标准为 2,750mm)
                         车宽: 1,850 mm / 车高: 1,734 mm (高重心)
                         空车: 1,690 kg / 满载 7 人: 2,200 kg+
```

### 1.1 车辆物理尺寸、轴距与质量分布 (Mass & Dimensions)
* **超长轴距（Wheelbase）**：**`3,055 mm`**（在整个 openpilot 适配车型库中名列前茅，普通轿车一般仅为 2.7m，SUV 一般为 2.85m）；
* **车身物理尺寸**：长 4,950 mm $\times$ 宽 1,850 mm $\times$ 高 1,734 mm；
* **整备质量与载荷跨度**：
  - 空载整备质量：**`1,690 kg`**；
  - 满载质量（7名成人 + 行李）：可达 **`2,200 kg ~ 2,300 kg`**；
  - **载荷跨度巨大**：空载与满载之间质量相差足足 500kg 以上，这对制动减速度与横向控制的自适应刚度提出了极高要求。

### 1.2 底盘与悬挂结构特性 (Chassis & Suspension)
* **前悬挂**：麦弗逊式独立悬挂；
* **后悬挂**：**扭力梁式非独立悬挂（Torsion Beam）**；
* **动力学特性影响**：
  - 扭力梁在抑制单侧车轮颠簸时，左右两侧车轮存在机械刚性耦合；
  - 车高达到 1.734m，车辆侧倾中心（Roll Center）偏高。若横向变道时角速度变化过猛，车体会出现明显的“横向剪切摇晃”，后排乘客极易晕车。

### 1.3 动力总成与 8AT 变速箱传动特性 (Powertrain)
* **动力单元**：Smartstream 1.5T / 2.0T 涡轮增压发动机；
* **变速箱**：**现代自研 8 速手自一体变速箱（8AT）**；
* **动力传动特征**：
  - 1 挡齿比大（通常约 4.8），2 挡齿比降至约 2.8。低速 1 挡升 2 挡（15~25 km/h 区间）时换挡落差明显；
  - 配备大容量液力变矩器，D 挡踩住刹车待机时存在较强的固有蠕动力矩。

### 1.4 车载网络与原厂 ADAS 电气拓扑 (CAN & ADAS)
* **总线拓扑**：现代经典 **500kbps 高速 C-CAN（非 CAN-FD）**；
* **线束接口**：`CarHarness.hyundai_k`，直接串联在原厂智能前视摄像头（LDWS / FCA 模块）插头处；
* **底盘控制执行器**：
  - **转向机 (EPS)**：支持线控扭矩注入（报文 `0x340 LKAS11`，50Hz）；
  - **制动与巡航**：支持原厂 SCC 自适应巡航控制报文注入。

### 1.5 原厂中控车机系统与底层硬件全景 (HSAE D531MC / 2.0GB RAM / i.MX6)
依据 2026-10-24 官方实测检测报告（`北京现代库斯途车机系统全景深度检测与分析报告_20261024.md`），库斯途原厂车机的真实物理软硬件规格如下：

## 二、优化方向一：超长轴距（3.055m）横向滞后消除与帕里斯帝大车 NNFF 模型移植

### 2.1 长轴距在高速大弯中的“画龙”与迟滞根因
传统 openpilot 默认的横向控制器（`latcontrol_torque.py`）通常以轿车物理参数为基线。将轿车参数直接套用在库斯途上，会产生两大物理冲突：
1. **转弯阻尼力矩不足**：3 米长轴距车辆的前轮转动惯量和偏航惯性矩（Yaw Moment of Inertia $I_z$）比轿车大约 **`35%`**，轿车力矩系数驱动库斯途转向机时，转向初段显得“发软”，进弯有推头感；
2. **后轮循迹滞后引起的过冲回正**：进弯后车辆偏航角速度建立较慢，算法误以为前轮转角不够，继续加大扭矩；当车身终于侧倾转入后，又出现转角过大，算法随后猛反打方向盘，在直道中心区形成微小的左右“画龙”摆动。

### 2.2 帕里斯帝（Palisade）大车力矩神经网络模型映射
现代旗下的**帕里斯帝（Palisade）**同属于 2 吨级、轴距近 3 米的大型大车平台，openpilot 社区为其训练了高精度的神经网络前馈模型（NNFF, Neural Network Feedforward）。

* **优化实施路径**：  
  在 `opendbc_repo/opendbc/car/torque_data/substitute.toml`（或分支对应文件）中添加映射：
  ```toml
  "HYUNDAI_CUSTIN_1ST_GEN" = "HYUNDAI_PALISADE"
  ```
* **优化收益**：
  - C3 的横向控制内核直接调用帕里斯帝针对大质量、长轴距训练的高阶前馈曲率网络；
  - 大半径弯道、高架匝道行驶时，方向盘转动力矩饱满细腻，彻底消除中心死区迟滞，**带来如德系豪华 MPV 般沉稳贴地的循迹手感**。

### 2.3 前馈偏航角滞后补偿 (Yaw-Rate Lead Filter)
在 `selfdrive/controls/lib/lateral_planner.py` 中，针对库斯途的 3.055m 轴距，增加基于一阶前馈超前的航向角补偿：

$$\delta_{lead} = \delta_{planned} + \tau_{lead} \cdot \frac{d\kappa}{dt} \cdot v_{ego}$$
其中 $\tau_{lead} = 0.15\text{ s}$。在检测到前方视觉曲率变化时，提前 150ms 给前轮施加微弱前置摆角，物理级抹平长轴距车辆的转向响应时延。

## 三、优化方向二：7座家用 MPV 满载舒适性与超平缓变道 S 曲线设计

### 3.1 后排老人小孩晕车机理 (Lateral Jerk Impact)
* **人体晕车（Motion Sickness）的本质是耳蜗前庭系统受到的横向加速度变化率（Jerk，加加速度）冲击**；
* 轿车变道通常追求干脆利索（3.0~3.5 秒内横切一个车道），横向加速度突变率可达 $0.15\text{ g/s}$；
* 库斯途高车身（1.73m）配合后排扭力梁，在快速变道时会产生**两阶段剪切横摆**（车头先切入，车尾在 0.5 秒后剧烈甩动）。第二排航空座椅上的老人和婴儿会受到强烈的离心力横甩，极易引发恶心晕眩。

### 3.2 变道完成时间由 3.5s 放宽至 5.0s 的非线性规划
在 `selfdrive/controls/lib/desire_helper.py` 中，将专属于库斯途的变道规划时间曲线进行重塑：

```python
# --------------------------------------------------------------------------
# 库斯途 7座 MPV 尊享平顺变道时间与曲线规划
# --------------------------------------------------------------------------
# 轿车标准变道速率: 步进减幅 2 * DT_MDL (约 3.0 秒切完)
# 库斯途 MPV 舒适平滑变道: 放宽至约 4.8 ~ 5.2 秒平缓切入
LANE_CHANGE_STEP_CUSTO = 1.2 * DT_MDL  # 平缓步进减幅

if self.lane_change_state == LaneChangeState.laneChangeStarting:
  # 平滑 S 型曲线减小车道线概率，避免猛打方向盘
  self.lane_change_ll_prob = max(self.lane_change_ll_prob - LANE_CHANGE_STEP_CUSTO, 0.0)
```

### 3.3 横向加速度限幅与冲击度控制 (Jerk-Limited Clamp)
* **侧向加速度限幅**：将变道期间允许产生的最大横向加速度严格钳制在 **$\le 0.08\text{ g}$**（原轿车模型允许达 $0.18\text{ g}$）；
* **横向冲击度（Jerk）控制**：限制在 **$\le 0.05\text{ g/s}$**。变道轨迹呈现极度优雅的“余弦平滑过渡线”，车内乘客即使闭目养神或手端热茶，也几乎感知不到车辆正在变道。

## 四、优化方向三：现代自研 8AT 变速箱起步顿挫消除与红灯蠕动锁零

### 4.1 1-2 挡大齿比升挡迟滞与顿挫根因
库斯途的现代自研前驱横置 8AT 变速箱，其 1 挡齿比高达约 4.8，2 挡齿比落差近 2.0。在城区堵车走走停停时，若 ACC 系统的起步请求加速度陡峭（如瞬间请求 $1.8\ \text{m/s}^2$）：
1. 发动机转速瞬间拉高至 2500rpm 以上；
2. 升入 2 挡时液力变矩器迅速锁止，产生强烈的**“拖拽点头感”**；
3. 随后前车减速，变速箱又匆忙降回 1 挡，造成频繁的前后拉扯。

### 4.2 起步加速度固化软化 (`ret.startAccel = 1.0`)
在 `opendbc_repo/opendbc/car/hyundai/interface.py` 中，针对库斯途（`HYUNDAI_CUSTIN_1ST_GEN`）固化起步加速度：

```python
# [interface.py]
if candidate == CAR.HYUNDAI_CUSTIN_1ST_GEN:
  ret.startAccel = 1.0  # 库斯途 8AT 专属: 固化起步加速度为 1.0 m/s² (原版默认 1.5~2.0)
```
* **效果**：起步时请求加速度呈抛物线温和爬升，变速箱在 15km/h 平稳滑入 2 挡，彻底告别起步顿挫。

### 4.3 高德红绿灯倒计时联动停稳锁零防蠕动 (`actual_stop_distance = 0.0`)
* **痛点**：由于液力变矩器怠速扭矩大，当车刹停在红绿灯路口时，若 openpilot 仅依靠前视摄像头视觉点识别前车或停止线，画面因路面微震轻微抖动时，车辆会出现“停稳后又往前耸一下”的微蠕动；
* **联动方案（`carrot_functions.py`）**：
  结合高德车机版广播同步传来的红绿灯实时状态（如 `🚦 红灯 92s`），当系统进入 `e2eStopped`（停稳）状态且红灯尚未转绿时，**强制将实际期望停止距离硬锁定为 0.0 米（`actual_stop_distance = 0.0`）**，ESC 保持深度制动压力，车子如钉在地上般稳固，绝不往前蠕动半寸。

## 五、优化方向四：库斯途原厂全液晶仪表盘联动点亮 (三屏一体化生态)

### 5.1 原厂 `0x485 LFAHDA_MFC` 20Hz 报文模拟机理
库斯途高配车型配备了全液晶仪表盘，原厂通过 CAN 总线接收前视多功能摄像头（MFC）发送的 `0x485 LFAHDA_MFC` 报文来驱动仪表中央的 ADAS 显示区。

很多改装方案安装 openpilot 后，原厂仪表盘中央要么是一片空白，要么亮起黄色故障灯。

```python
# [opendbc/car/hyundai/hyundaican.py]
def create_lfahda_mfc(packer, enabled, hda_set_speed):
  values = {
    "LFA_Icon_State": 2 if enabled else 1,     # 2: 绿色激活方向盘, 1: 白色待命
    "HDA_Icon_State": 2 if enabled else 0,     # 2: 激活高速公路驾驶辅助 (HDA) 蓝绿字标
    "HDA_SysState": 1 if enabled else 0,
    "HDA_SetSpeed": hda_set_speed,            # 仪表盘同步显示巡航设定车速
  }
  return packer.make_can_msg("LFAHDA_MFC", 0, values)
```

### 5.2 仪表盘车道线绿化、绿色方向盘与 HDA 标志激活
由 C3 内置的 Comma Panda 硬件每隔 50ms（20Hz）向原厂 C-CAN 总线发送该报文：
* **车道线由白变绿**：仪表盘左右两条车道线即刻变为高亮鲜绿色，代表车道居中保持已接管；
* **绿色方向盘图标亮起**：仪表盘中央点亮代表智能巡航的高级绿色方向盘小图标；
* **点亮 HDA 标识**：在高速公路上激活现代原厂“HDA 高速领航辅助”的高端专属标志。

### 5.3 “原厂液晶仪表 + 车机竖屏 HUD + C3小屏”三屏协同生态

## 六、优化方向五：MPV 超大前风挡高暴晒下的极端夏日温控与功耗优化

### 6.1 夏季暴晒中控台 70℃ 聚热机理
* 库斯途作为典型 MPV，为营造开阔的前排视野，**前风挡玻璃面积接近 1.5 平方米，且玻璃倾角极为平缓**；
* 夏季户外烈日直射时，中控台顶部的塑料件表面温度经常飙升至 **`70℃ 以上`**；
* 安装在后视镜旁边的 Comma 3 设备，如果持续处于高负载或待机功耗过大，极易在驻车暴晒时触发高通骁龙 845 的过热保护断电（Thermal Shutdown）。

### 6.2 驻车待机 (Offroad) CPU 大核下线策略（实现状态已修订）
在 `system/hardware/tici/hardware.py` 中，固化以下温控策略：

1. **熄火驻车（Offroad 状态）**：
   - 自动下线 CPU 4~7（4 个高发热的 Kryo 385 Gold / A75 大核），仅保留 4 个超低功耗的 Silver 小核处理轻量任务 —— 该项属实（hardware.py:366-374）；
   - **方向修正**：代码在 hardware.py:421-422 对 force_clk_on / force_rail_on 写入的是 1（强制开启 GPU 时钟与供电轨），并非"释放"；本文原写的 0 与代码相反，已修正；
   - **数字撤回**：整机待机 1.65 W、核心 39℃ 两项无任何代码或实测依据，已从本文删除；如需作为结论，须补实机功耗与温度实测（口径见 32 号裁决第六节）；
2. **点火行驶（Onroad 状态）**：
   - 底盘点火信号触发瞬间，瞬间拉起全量 8 核与 GPU 性能模式，风扇阶梯式静音控温，确保高强度模型推理无掉帧。
