# 32 RAM 口径统一裁决与内存安全论证修订

> 用途：库斯途车机 RAM 与内存相关口径的唯一真相源。后续所有文档、"闭环"声明与验收结论以此为准。
> 权威证据：北京现代库斯途车机系统全景深度检测与分析报告_20261024.md §1.3（/proc/meminfo 实测原始输出）
> 裁决日期：2026-11-03
> 裁决结论：车机物理 RAM 为 2.0 GB（MemTotal 2,059,512 kB）；"1GB / 扣除显存后可用 350~400MB"为错误口径，作废。
> 关联：30 号主索引表 M-34、31 号审核意见第四节

## 一、权威证据与裁决

| 项 | 实测值（2026-10-24 报告 §1.3） | 含义 |
| :--- | :--- | :--- |
| MemTotal | 2,059,512 kB ≈ 2.0 GB | 内核可见总物理内存 |
| MemFree | 152,092 kB ≈ 150 MB | 某一时刻的瞬时空闲，不含 buffers/cached，不等于系统可用上限 |
| 该报告结论原文 | "总内存：2.0 GB ... 系统调度极其充裕"、"i.MX6Q 四核 + 2GB 运存运转极其平稳" | 与 22 号总纲"极端物理局限"的基调相反 |
| docs/custin/VEHICLE_DYNAMICS.md | 2.0 GB，MemTotal 2,059,512 kB | 仓库内 70ba3d8 提交已采用 2.0GB |
| 21 号指南 §1.5.2 | 2.0 GB，MemTotal 2,059,512 kB，MemFree 152,092 kB | 与原始报告逐字一致 |

裁决：2.0 GB 为唯一权威口径。22 号总纲、23 号提示词中的"1GB / 可用 350~400MB"属错误前提，本轮已修订；25 / 28 号报告中的"140MB+ 缓冲"属旧口径推论，不再作为验收依据。

## 二、三个必须区分的概念

| 概念 | 值 | 说明 |
| :--- | :--- | :--- |
| 物理 RAM 总量 | 2.0 GB | MemTotal，芯片与内核可见的总量 |
| 瞬时空闲 | 约 150 MB | MemFree，抓取瞬间的未分配页 |
| 应用占用 | PSS | dumpsys meminfo 的 TOTAL PSS，须用未裁剪原始输出 |

22 号把"扣除 GPU/VPU 保留后可用 350~400MB"当成总量上限，并据此推导 209 + 250 = 459 > 350 必然触发 LMK——前提与实测不符，该推导作废。

## 五、重算后的内存安全论证

1. 高德常驻约 209 MB、原版伴侣应用可达 250MB+，合计约 459 MB；在 2.0 GB 总内存下不构成必然触底。
2. 真正的约束是：实测 MemFree 约 150 MB 的瞬时空闲、Android 4.4 Dalvik 的 LMK 阈值、以及 R 挡影像服务抢占屏幕的 0.5 秒时序。
3. 因此"35MB 警戒线 / 140MB 缓冲带 / 50MB 红线 / 209+250>350 触发 LMK / 100% 毫秒级秒开"等旧口径结论全部撤回，改以实机证据判定。
4. 伴侣应用 PSS 以 25 / 28 号实测的 15.2 / 15.5 MB 为当前最佳可用值；22 号的 3.5 MB 常驻与 35~55 MB 峰值为旧口径，需未裁剪 dumpsys 原始输出复核后才能定论。
