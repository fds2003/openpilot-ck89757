## 2. 启动与进程检查

### 2.1 进程

```bash
pgrep -af 'carrot_man|lane_runner|selfdrive.carrot.lane'
```

- [ ] `carrot_man` 存在且只有 **1 个**（禁止双实例）。
- [ ] `lane_runner` 存在（onroad 时）。
- [ ] 无 `MultiplePublishersError`。
- [ ] `lane_runner` 未打印 `lane_runner disabled`。

### 2.2 端口与 owner

```bash
ss -ulnp | grep -E ':(4210|4211|4213|4215|7705|7706)\b'
```

- [ ] 4210/4211/4213/4215/7705/7706 均绑定 `0.0.0.0`（或预期网卡 IP）。
- [ ] 每个端口**只有一个 owner**（均为 `carrot_man` 的线程）。
- [ ] 7710/7709/12345 仍为 `127.0.0.1`（管理通道不应放开）。

### 2.3 参数

```bash
python - <<'EOF'
from openpilot.common.params import Params
p = Params()
for k in ("CarrotCooperativeMode", "CarrotUdpAllowedIps"):
    print(k, "=", p.get(k))
EOF
```

- [ ] `CarrotCooperativeMode` 为 `1`（协同）或 `0`（旧行为），与预期一致。
- [ ] `CarrotUdpAllowedIps` 为空（同网段模式）或包含车机 IP（严格模式）。

## 3. 链路验证（三段）

### 3.1 第一段：设备发现（5510 ↔ 4210）

车机侧：

```bash
adb logcat -s AmapNavi:* | grep -i "discover\|c3_pong\|device"
```

C3 侧抓包：

```bash
sudo tcpdump -i wlan0 -n -A 'udp port 4210 or udp port 5510' -c 20
```

- [ ] 车机每 5s 发出 `{"cmd":"discover","port":5510}`。
- [ ] C3 返回 `{"resp":"c3_pong",...}`。
- [ ] 车机设备页显示 C3 IP。
- [ ] C3 日志无 `UDP rejected source: <车机IP>`。

### 3.2 第二段：车机 → C3 指令（7705）

车机侧触发一次变道意图（驻车可用设置页/测试入口，或 Reborn 的调试方式）。

C3：

```bash
sudo tcpdump -i wlan0 -n -A 'udp port 7705' -c 5
```

期望：

```json
{"cmd":"LANECHANGE","direction":"LEFT","arg":"LEFT","param":1,"seq":N,"index":N,"v_cruise":0,"blinker":1,"timestamp":...}
```

- [ ] 报文到达 C3。
- [ ] `carrotMan.carrotCmd` 在 rlog 中变为 `LANECHANGE`：
  ```bash
  grep -a "carrotCmd" /data/media/0/realdata/rlog/* | tail
  ```
- [ ] 无重复触发（同一 `index` 只执行一次）。

### 3.3 第三段：C3 → 车机遥测（7706）

C3：

```bash
sudo tcpdump -i wlan0 -n -A 'udp port 7706' -c 5
```

- [ ] 约 10–20Hz 的 JSON 到达车机 IP:7706。
- [ ] 车机 HUD 车速与仪表一致。
- [ ] 前车距离/盲区卡片随实车变化。
- [ ] 断开 C3 后 1.5s 内 HUD 进入断联态（`TelemetryWatchdog`）。

### 3.4 车道类型（4213）

```bash
sudo tcpdump -i wlan0 -n -A 'udp port 4213' -c 5
```

- [ ] `lane_runner` 在 onroad 时持续发送 `{"resp":"lane",...}`。
- [ ] C3 `shared_data.left_lane/right_lane` 随画面变化：
  ```bash
  grep -a "left_lane" /data/media/0/realdata/rlog/* | tail
  ```
- [ ] CPU 占用可接受（20Hz）：
  ```bash
  top -b -n1 | grep -E "lane_runner|carrot_man"
  ```

### 3.5 红绿灯（4215，使用 adbridge 时）

```bash
sudo tcpdump -i wlan0 -n -A 'udp port 4215' -c 5
```

- [ ] 仅在高德有红绿灯广播时出现。
- [ ] `carrot_serv.traffic_state` 随之变为 1（红）/2（绿）。
- [ ] 3s 无更新后清零。

## 4. 功能验证

### 4.1 高德解码（Reborn）

- [ ] 高速路段：日志/界面显示"高速"判定为真（`isHighway=true`）。
- [ ] 13012 车道包到达时，推荐/禁行车道非空。
- [ ] 限速、TBT、红绿灯字段随高德导航变化。

### 4.2 安全门禁

| 场景 | 期望 |
|---|---|
| 目标车道实线 | 阻断，原因 `SOLID_LINE` |
| 目标侧前角雷达有车 | 阻断，原因 `FRONT_BLIND` |
| 目标侧 BSD 报警 | 阻断，原因 `BSD_ALARM` |
| 目标侧激光盲区 | 阻断，原因 `LIDAR_HAZARD` |
| 目标车道前车 < 20m | 阻断，原因 `TARGET_LANE_OCCUPIED` |
| 后向 TTC < 2.5s | 阻断，原因 `LIDAR_HAZARD` |
| 遥测丢失 > 1.5s | 撤销变道，`TELEMETRY_LOST` |

- [ ] 逐项在台架或封闭场地验证，记录实际原因码。

### 4.3 协同模式

- [ ] 协同模式开启 + 车机在线：C3 **不自行打灯/转向**（观察 10 分钟）。
- [ ] 车机断电/断网 15s：C3 恢复自主 ATC（观察是否按导航转向）。
- [ ] 车机恢复在线：C3 再次停止自主转向。
- [ ] 协同模式关闭：C3 恢复原行为。

### 4.4 信任策略

- [ ] 同网段新设备首次连接：被学习并放行。
- [ ] 跨网段设备：被拒绝，日志出现 `UDP rejected source`。
- [ ] 配置 `CarrotUdpAllowedIps` 后：未列出的同网段设备被拒绝。

## 5. 日志检查点

| 关键字 | 含义 | 处置 |
|---|---|---|
| `MultiplePublishersError` | 双发布者 | 检查 process_config，禁止双实例 |
| `lane_runner disabled` | 缺 onnxruntime 或模型 | 安装 requirements / 检查模型路径 |
| `UDP rejected source` | 信任策略拒绝 | 检查网段/白名单 |
| `whitelist learning same-subnet` | 学习新设备 | 确认是车机 IP |
| `Discovery bind error` | 4210 被占用 | `ss -ulnp` 查 owner |
| `Cmd bind error` | 7705 被占用 | 同上 |
| `traffic light bind error` | 4215 被占用 | 同上 |
