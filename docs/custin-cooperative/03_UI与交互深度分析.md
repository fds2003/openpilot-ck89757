## 一、页面清单与架构总览

通过反编译 AXML 与 `R.layout` 深度映射，AmapNavi 包含 7 个独立 Activity 页面、2 个列表/弹窗组件：

| 序号 | 布局文件名 | 绑定组件类 | 页面定位 | 核心交互特性 |
| :---: | :--- | :--- | :--- | :--- |
| **1** | `activity_main.xml` | `MainActivity` | **主监控中枢与全景 HUD 仪表** | 左右车速表盘、高德车道指引、限速悬浮按钮、雷达卡片抽屉、ONNX 实时车道线预览与决策日志。 |
| **2** | `activity_setting.xml` | `SettingActivity` | **通用参数设置工作台** | 包含“通用/领航/超车”三大顶部 Tab，Flexbox 流式开关布局，带 ± 步进数值输入。 |
| **3** | `activity_nav_setting.xml`| `NavSettingActivity` | **车道级领航专属设置** | 高速/公路领航细则、推荐车道与禁行车道策略、分岔距离设定、匝道平滑曲线减速参数。 |
| **4** | `activity_overtake_setting.xml`| `OvertakeSettingActivity`| **自主超车设置工作台** | 超车激进/常规/保守模式单选、激光雷达侧向阈值（固定距离/时距切换）、反向冷却计时配置。 |
| **5** | `activity_log_manager.xml`| `LogManagerActivity` | **本地决策日志管理台** | 分栏筛选 `app/` 主日志与 `overtake/` 超车日志，集成刷新、单选删除、一键全删与系统分享。 |
| **6** | `activity_udp_client.xml` | `UdpDeviceActivity` | **C3 局域网设备扫描界面** | 启动/停止 UDP 组播探针，动态 RecyclerView 呈现局域网内 Comma 3 设备 IP 与 ID。 |
| **7** | `activity_wxpay.xml` | `WxPayActivity` | **开发者自愿赞助打赏弹窗** | 极简深色全屏弹窗，展示个人微信收款码 ImageView 与关闭按钮。 |
| **8** | `item_device.xml` | `DeviceAdapter` | **设备列表条目子项** | 单行设备 IP 与状态展示。 |
| **9** | `custom_dialog.xml` | 通用弹窗组件 | **操作二次确认对话框** | 删除日志二次确认与关键操作防误触。 |

## 二、设计系统与视觉规范

### 2.1 基础色彩规范 (Color Tokens) 【已确认】
该应用针对车载夜间防眩光与高对比度需求，建立了以深黑/高亮双对比为主的视觉设计系统：

| Token 名称 | 十六进制色值 | 规范用途与语义 |
| :--- | :--- | :--- |
| **背景色 (Background Base)** | `#FF000000` (Pure Black) | 页面全局纯黑底色，适配 OLED/车载屏夜间驾驶无漏光防眩晕。 |
| **卡片/抽屉底色 (Surface Layer)**| `#FF1E1E1E` ~ `#FF2D2D2D` | 设置面板、雷达卡片容器、代码日志区域的二级浅深色。 |
| **主要文本色 (Text Primary)** | `#FFFFFFFF` (Pure White) | 关键信息、当前车速、主路限速、操作标题。 |
| **次要文本色 (Text Secondary)** | `#FFB0B0B0` (Cool Grey) | 辅助说明、单位标注（km/h, 秒, 米）、未选中状态。 |
| **安全/推荐色 (Success Accent)** | `#FF00E676` (Neon Green) | 推荐车道高亮、巡航开启、雷达盲区安全净空无车。 |
| **警告/注意色 (Warning Accent)** | `#FFFFD600` (Vivid Amber)| 侧后方有车逼近、前车压速、进入匝道准备区。 |
| **危险/阻挡色 (Danger / Error)** | `#FFFF1744` (Vivid Crimson)| 盲区报警、实线禁止跨越变道、禁行车道（X）、命令超时熔断。 |
| **导航品牌蓝 (Nav Accent)** | `#FF2979FF` (Cobalt Blue) | 高德导航联动状态、常规功能激活按钮。 |

### 2.2 字体排印体系 (Typography) 【已确认】
车载交互要求在驾驶员余光扫视（0.3秒 Glance）时能够清晰辨别数字：
- **超大仪表车速 (Dashboard Speed)**：`36sp ~ 44sp`，加粗 (`textStyle="bold"`)，居中陈列。
- **导航指引主文字 (TBT Main Text)**：`18sp ~ 22sp`，高亮白色，抗锯齿。
- **参数分组标题 (Section Header)**：`16sp`，粗体，带下划细线分割。
- **常规表单与按钮 (Body & Button)**：`14sp ~ 15sp`，保证车机触控屏清晰易辨。
- **系统日志与微型标注 (Console / Footnote)**：`10sp ~ 12sp`，等宽字体排布。

### 2.3 触控尺寸与防误触间距 (Ergonomics Touch Targets) 【已确认】
- **车载大按钮尺寸**：限速调节按钮（`btnIncRoadLimit`, `btnDecRoadLimit`）高度为 `36dp ~ 48dp`，宽度采用整行平铺或 `match_parent`。
- **微调步进控件**：所有的参数加减按钮（`-` / `+`）强制规范为 `48dp × 36dp`，间距大于 `8dp`，严格契合车载行驶抖动环境下的手指点击容错阈值。

## 三、核心页面布局与组件层次拆解

### 3.1 主控 HUD 仪表与多层调试工作台 (`activity_main.xml`) 【已确认】

主界面采用 `FrameLayout` 作为根容器，实现了“HUD 基础工作台”与“全景超车雷达抽屉”双层重叠架构：

```
activity_main.xml 结构层次:
┌────────────────────────────────────────────────────────┐
│ FrameLayout (全屏根容器)                                │
│ ├─ Layer 1: LinearLayout#containerLinearLayout (主视图)  │
│ │   ├─ 顶部车速与导航条: [左表盘] [导航信息/距离] [右表盘]  │
│ │   ├─ 状态栏: [高德连接状态] [软件版本号]                 │
│ │   ├─ 设备栏: [已连接 C3 硬件 ID]                      │
│ │   ├─ 车道栏: [高德车道指示箭头] [视觉车道线状态]          │
│ │   ├─ 快捷按钮栏: [超车] [设置] [OP参数] [设备] [赞助] [>>]│
│ │   ├─ 限速控制组: [▲ 限速+5] [▼ 限速-5] [↺ 重置]        │
│ │   ├─ 视觉预览: [ImageView 车道线实时推理画面]            │
│ │   ├─ 设备/日志控制: [日志] [导出] [概览] [清空] [复制]   │
│ │   └─ 下部区域: [ScrollView 导航决策 Trace 文本滚动区]     │
│ └─ Layer 2: LinearLayout#layoutOvertakeDebug (超车抽屉) │
│     ├─ 顶部信息: [超车目标侧车速与时距]                     │
│     ├─ 雷达矩阵: overtakeCardsWrap (6块雷达卡片)          │
│     ├─ 决策详情: tvOvertakeDebug (详细决策规则判定文本)     │
│     └─ 底部操作: [记录日志开关] [发日志按钮] [关闭抽屉]     │
└────────────────────────────────────────────────────────┘
```

#### 关键控件映射表
- `speed_left` / `tvSpeedLeft` (50dp×50dp)：左侧实时自车车速显示。
- `speed_right` / `tvSpeedRight` (50dp×50dp)：右侧巡航设定车速显示。
- `tvNavInfo` & `tvDistance`：显示高德下个转弯路口主文字与剩余距离。
- `driveWayTextView` & `vLaneTextView`：高德车道指引符号（↑↑→⛔）与 AI 视觉左右标线状态。
- `btnIncRoadLimit` / `btnDecRoadLimit` / `btnResetRoadLimit`：车载大触控限速偏置调节按钮。
- `imageView` (`imageViewLinear`)：实时呈现前置摄像头捕获与叠加 416×416 YOLO-seg 掩膜的车道线图像。

```
├──────────────────────┼──────────────────────┼──────────────────────┤
│ [tvRadarLidarLeftRear]│  [tvRadarEgo]        │ [tvRadarLidarRightRear
│  左侧后向激光雷达     │   自车本车状态卡片   │  右侧后向激光雷达     │
```

  - 盲区严重报警/实线：背景变猩红，阻断变道。

### 3.3 通用参数设置面板 (`activity_setting.xml`) 【已确认】

采用 `ScrollView` 嵌套 `LinearLayout`，顶部设计了一体化的三段式 Tab 切换栏（`btnGotoGeneral`, `btnGotoNav`, `btnGotoOvertake`）：

1. **红绿灯与停车辅助区**：
   - `cbNaviTrafficAssist`（APP辅助停车）、`cbCpTrafficAssist`（OP视觉辅助）、`cbRedLightTrafficAssist`（导航红灯辅助）。
   - 带 `btnMinusCpMinSpeedLimt` / `btnPlusCpMinSpeedLimt` 调节目标车速。
2. **AI 视觉与车道线配置区**：
   - 复选框组：`cbLaneDetect`（车道线检测）、`cbVideoShow`（显示视频画面）、`cbLaneShow`（显示车道线）、`cbLaneTypePublish`（实线结果发送给OP）、`cbVideoShowFast`（高帧率模式）、`cbLaneColor`（彩色/灰度）。
   - `etLaneDetectInterval`：检测周期设定（默认 500ms），配 48dp 步进按钮。
3. **视觉车道模式单选组 (`rgVisionLaneMode`)**：
   - 快速（Fast）、标准（Normal）、保守（Slow）。
4. **道路限速与偏置微调区**：
   - 最低道路限速 (`etMinSpeedLimit`)、最高道路限速 (`etMaxSpeedLimit`, 默认 130km/h)。
   - 提高道路限速百分比 (`etRoadSpeedLimitPercent`)、固定偏置 (`etRoadSpeedLimitKph`)。
   - 高速低速提速偏置 (`etOffsetHighway` / `etOffsetRoad`)。
5. **车机适配专区**：
   - `etTopPad`：APP顶部留空（0~100dp），针对库斯途等原车状态栏遮挡提供像素级避让。
6. **开发者高级工具**：
   - `btnSettingInstallFlask`（安装 Flask）、`btnSettingInstallOpencv`（安装 CV2 库）、`btnSettingLaneTest`（启动车道线标定测试）。

### 3.4 车道级领航专属设置面板 (`activity_nav_setting.xml`) 【已确认】

专注于高德地图导航车道级控制策略：

1. **领航策略开关（Flexbox 弹性多行）**：
   - `cbNavSettingAppNavi`（车道领航-高速）、`cbNavSettingAppRoadNavi`（车道领航-公路）。
   - `cbNavSettingSuggestLane`（走推荐车道）、`cbNavSettingDisLane`（避开禁行车道）。
   - `cbNavSettingKeepLeft`（提前靠左）、`cbNavSettingKeepRight`（提前靠右）、`cbNavSettingVisionKeepRight`（纯视觉提前靠右）。
   - `cbNavSettingSafetyLegacy`（宽松变道条件，针对老旧车机雷达去抖）。
   - `cbNavSettingLastLaneSuppress`（车辆已靠边后禁止继续变道）。
   - `cbNavSettingSpeak`（领航播报）、`cbNavSettingSpeakFirst`（先播报后变道）。
2. **领航模式 (`rgNavSettingMode`)**：
   - 激进（快速变道入主线）、标准、保守（长距离跟车）。
3. **关键距离阈值精细微调**：
   - 最低车速：默认 `20 km/h`；
   - 变道控制距离：高速默认 `2000 m`，低速默认 `500 m`；
   - 分岔路口距离：高速默认 `80 m`，低速默认 `30 m`；
   - 临匝道放宽偏移：高速默认 `10 m`，低速默认 `5 m`。
4. **匝道自适应减速配置卡片**：
   - `cbNavSettingRampSlowdown`（匝道提前减速总开关）；
   - 减速开始距离：高速 `400 m`，低速 `200 m`；
   - 匝道目标车速：高速 `60 km/h`，低速 `45 km/h`；
   - 驶入后维持时间：`etNavRampHold`，默认 `10 秒`。

### 3.5 自动超车参数设置面板 (`activity_overtake_setting.xml`) 【已确认】

专为自动超车变道设计的参数调校台：

1. **超车模式单选 (`rgOvertakeSettingMode`)**：
   - **激进 (Fast)**：较小跟车时距容忍，较快发起变道；
   - **常规 (Normal)**：标准工况；
   - **保守 (Slow)**：大时距等待，严格侧向净空。
2. **场景开关与前置阻挡规则**：
   - `cbOvertakeSettingHighway`（高速超车）、`cbOvertakeSettingRoad`（公路超车）；
   - `cbOvertakeBlockBlockedLane`（有禁行车道 X 时禁止超车，防止盲目变入危险车道）；
   - `cbOvertakeBlockSuggestLane`（有导航推荐车道时禁止自作主张超车）。
3. **侧向激光雷达多模式阈值设置**：
   - 前向阈值模式：支持“固定距离 (`rbFrontThreshFix`，默认 5.0m)”与“速度时距 (`rbFrontThreshTime`，默认秒数)”切换；
   - 后向阈值模式：支持“固定距离 (`rbRearThreshFix`，默认 10.0m)”与“速度时距 (`rbRearThreshTime`)”切换；
   - 相对速度外推接近时距：前向默认 `4.0 s`，后向默认 `4.0 s`。
4. **反向变道防横跳冷却**：
   - `etReverseCooldown`：反向变道冷却时间（默认 `20 秒`），配 48dp 步进按钮。

## 四、车载横屏人机工效与交互动效规范

### 4.1 横向分栏黄金视野分区 【高度可信】
库斯途等现代车系车机屏幕普遍为 10.4 英寸以上横向或竖向宽屏，AmapNavi 布局遵循严格的车载安全工况分区：

```

┌─────────────────────┬───────────────────────────┬──────────────────────┐
```

### 4.2 触摸容错与误触阻尼机制 【已确认】
1. **数值增减防误触**：所有的输入框（`EditText`）均禁用了软键盘直接弹出（车机行驶中弹出输入法极易遮挡视线），强制通过两翼的 `[-]` 和 `[+]` 实体大按钮点击增减。
2. **多重点击防抖动 (Click Debounce)**：按键点击事件中内置了毫秒级去抖（500ms），杜绝颠簸路况下手抖造成的连点重跳。
3. **关键操作防呆设计**：清空日志、重置系统配置均弹出系统级 Modal 对话框进行二次确认。
