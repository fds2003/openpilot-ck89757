## 4. 原版 APK 的实测结论

- 包名/版本：`com.carrot.amapnavi` / 1.3.6.9 (31)，调试证书。
- 类数：2620；应用代码 85（主包 81 + lane 4）。
- 端口：7705 收、7706 发、4210 收、4211 发、4213 发、5510/4210 发现；
  5210/4212 未使用。
- 遥测：81 字段（34 Bool / 15 Float / 32 Int）。
- 高德：10001 + 13012；`ROAD_TYPE` 转换；车道 JSON。
- 上行指令：仅 `carrotCmd=LANECHANGE`。
- 无任何原始导航数据上行。

---

## 5. Reborn 当前能力

- 高德解码：10001 / 13012 / ROAD_TYPE / 车道 JSON。
- 决策：超车状态机、三档参数、冷却、CANCEL。
- 安全：实线、BSD、激光、前角、目标车道、TTC、净空。
- 通信：7706 收、7705 发、5510/4210 发现。
- 无端侧视觉、无 4213/4211 发送（车道由 C3 负责，转向灯随指令携带）。
