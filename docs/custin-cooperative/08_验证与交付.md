## 3. 真实模型实测

环境：PC / Python 3.12 / onnxruntime 1.31.1（CPU）/ numpy 2.5.4。

### 3.1 模型契约

| 项 | 实测 |
|---|---|
| 输入 | `images` `[1,3,416,416]` float |
| 输出 | `output0` `[1,42,3549]`、`output1` `[1,32,104,104]` |
| opset | 17 |
| 类别 | 0 divider、1 dotted、2 double、3 random、4 road-sign、5 solid |

### 3.2 真实图像

APK 自带 `test1.jpg` / `test1_640_480.jpg`：

- 检出 8 条线；
- 主要目标：cls=1（虚线）0.960、cls=5（实线）0.958；
- 判定"左虚、右实"；
- RGB/BGR 结果一致，按 APK 采用 RGB；
- 坐标范围为像素（0–416），非归一化。

### 3.3 端到端耗时（本机 CPU，非 C3）

| 阶段 | 耗时 |
|---|---|
| 预处理 | 4.86 ms |
| 推理 | 35.46 ms |
| 后处理 | 3.34 ms |
| 合计 | **43.66 ms**（20Hz 预算 50ms） |

> C3 上需实测 OpenCL/CPU；若超 50ms，降频到 10–15Hz 或换 QNN/NNAPI。
