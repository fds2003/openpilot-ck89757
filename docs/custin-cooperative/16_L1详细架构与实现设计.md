## 0. 范围与约束

### 0.1 本期范围

- 高德导航时，Reborn 解码导航广播并写 HSAE 仪表。
- 仪表通道：TBT、限速、行程、文本行。
- 单写者策略：仅高德导航有效时写，退出/超时交还。

| targetSdk 22 | 无运行时权限；安装即授予 |

## 1. 架构设计

### 1.1 系统上下文

```
┌──────────────────────────── 车机 ────────────────────────────┐
│                                                              │
│  高德车机版                                                   │
│    │ AUTONAVI_STANDARD_BROADCAST_SEND (10001/13012/10019)     │
│    ▼                                                         │
│  ┌──────────────────────────────────────────────────────┐    │
│  │ Reborn                                               │    │
│  │                                                      │    │
│  │  AmapBroadcastDecoder ── StateFlow<NaviState>        │    │
│  │          │                                           │    │
│  │          ▼                                           │    │
│  │  ClusterRuntime ── ClusterPublisher ── ClusterMapper │    │
│  │                                      │               │    │
│  │                                      ▼               │    │
│  │                              ClusterTransport         │    │
│  │                                      │               │    │
│  │                          HsaeClusterTransport         │    │
│  └──────────────────────────────────────┼───────────────┘    │
│                                         │ Binder             │
│                                         ▼                    │
│                              原厂仪表（HSAE）                 │
│                                                              │
│  百度 ADAS（保留，回退）──Binder──► 原厂仪表                  │
│  DuerOS（默认导航=Amap）──广播──► 高德                        │
└──────────────────────────────────────────────────────────────┘
```

### 1.2 组件与职责

| 组件 | 职责 | 依赖 | 可单测 |
|---|---|---|---|
| `AmapBroadcastDecoder` | 解析高德广播，维护 `NaviState` | Android Intent | ✅（构造 Intent） |
| `ClusterRuntime` | 生命周期、调度、Flow 收集 | Publisher、协程 | ❌ |
| `ClusterPublisher` | 状态机、去重、节流、保活、交还 | Transport、Settings、Clock | ✅ |
| `ClusterMapper` | NaviState → ClusterFrame 纯映射 | 无 Android | ✅ |
| `ClusterTransport` | 仪表写入抽象 | 无 | ✅（Fake） |
| `HsaeClusterTransport` | 反射 ServiceManager + Parcel | Android Binder | ❌（实车） |
| `ClusterSettings` | 读取/监听配置 | UserSettingsRepository | ✅ |
| `ClusterSettingsTabController` | 第一级“仪表投影”页面的控件绑定与状态展示 | Publisher/Runtime | ❌ |
| `RelayEngine` | 现有中继引擎，挂接 Runtime | 全部 | 部分 |

### 1.3 分层与依赖规则

```
core/model, core/util          ← 纯 Kotlin
data/amap                      ← Android Intent + 纯 Kotlin Codec
cluster/mapper, cluster/model  ← 纯 Kotlin
cluster/transport              ← Android Binder
cluster/runtime                ← Android + 协程
ui/setting                     ← Android UI
```

规则：

1. `ClusterMapper` 不得 import `android.*`，保证 JVM 单测。
2. `ClusterPublisher` 不得直接持有 `Context`。
3. `HsaeClusterTransport` 之外不得出现 `Parcel` / `IBinder`。
4. UI 只读 `StateFlow<ClusterStatus>`，不直接调 Transport。

### 1.4 运行时数据流

```
高德广播
  → AmapBroadcastDecoder.onReceive（主线程）
  → _naviStateFlow.value = copy(...)
  → RelayEngine.scope 收集
  → ClusterRuntime.onNaviState(navi)   // 只写 volatile
  → ClusterPublisher.tick()            // 单线程调度，100ms
  → ClusterMapper.toFrame(navi)
  → 变化检测/节流
  → ClusterTransport.sendXxx()
  → Parcel.transact()
  → 原厂仪表
```

### 1.5 线程模型

| 线程 | 工作 | 约束 |
|---|---|---|
| 主线程 | BroadcastReceiver 解析、UI | 不做 Binder、不做 I/O |
| `Dispatchers.Default` | RelayEngine Flow 收集 | 只写 `volatile` 最新值 |
| `cluster-tick`（单线程 ScheduledExecutor） | `tick()`、映射、Binder 调用 | 串行，避免 Binder 并发 |
| UI 线程 | 读 `StateFlow` 状态 | 不直接调 Transport |

关键点：

- `tick` 周期 100ms，但实际发送频率由节流控制（TBT ≤2Hz、限速 ≤1Hz、文本 ≤1Hz、行程 ≤0.1Hz）。
- Binder 调用同步阻塞，只允许在 `cluster-tick` 线程。
- `onNaviState` 不分配大对象，只保存引用。

### 1.6 状态机

```
                 cluster_enable=true
                 && navi.navValid
                 && 3s 内有广播
RELEASED ───────────────────────────────► ACTIVE
   ▲                                        │
   │  cluster_enable=false                  │ 导航结束
   │  或 3s 无广播                           │ 或 3s 无广播
   │  或 RelayEngine.stop()                  │ 或 开关关闭
   └────────────────────────────────────────┘
                    release()
```

| 状态 | 含义 | 行为 |
|---|---|---|
| `RELEASED` | 不持有仪表 | 不发送；等待条件 |
| `ACTIVE` | Reborn 持有仪表 | 发送变化帧 + 保活 |
| `ACQUIRING` | 预留（L2 握手用） | L1 不使用，直接 RELEASED→ACTIVE |
| `RELEASING` | 预留（延时交还） | L1 同步执行交还 |

### 1.7 失效与降级

| 故障 | 检测 | 处理 |
|---|---|---|
| HSAE 服务不存在 | `ServiceManager.getService` 返回 null | 状态 `ServiceMissing`，不重试刷屏（每 5s 重试一次） |
| 无权限 | `SecurityException` | 状态 `PermissionDenied`，停止写入，UI 提示 |
| Binder 死亡 | `DeadObjectException` / `!isBinderAlive` | 清空 binder，下个 tick 重取 |
| transact 返回 false | 返回值 | 记录错误，下个 tick 重试；连续 3 次禁用该通道 |
| 高德广播中断 | `now - lastNavAt > 3000` | 交还 |
| 映射异常 | try/catch | 跳过该帧，不崩溃 |
| 配置读取异常 | try/catch | 使用默认值 |

### 1.8 单写者策略

L1 采用“高德优先 + 不主动抢”：

```
if (!cluster_enable) -> RELEASED
else if (!navi.navValid || now-lastNavAt > 3000) -> RELEASED
else -> ACTIVE
```

- 只开高德：Reborn 写。
- 只开百度 ADAS：Reborn 不写，ADAS 自己写。
- 两个都开：最后写入者覆盖；设置页显示警告，不自动仲裁。
- 退出高德：交还（`displayType=3` → `8` → 清文本）。

### 1.9 配置项

| Key | 默认 | 说明 |
|---|---|---|
| `cluster_enable` | **false** | 总开关 |
| `cluster_tbt_enable` | true | TBT 箭头/距离 |
| `cluster_speed_enable` | true | 限速圆牌 |
| `cluster_est_enable` | true | 行程剩余 |
| `cluster_text_enable` | true | 路名/红绿灯文本 |
| `cluster_tl_enable` | true | 文本行是否含红绿灯 |
| `cluster_eta_mode` | 1 | 1=到达时刻，2=剩余时长 |

#### 2.4.3 统一 transact

```kotlin
private fun transact(
    binder: IBinder?,
    descriptor: String,
    code: Int,
    write: (Parcel) -> Unit
): Boolean {
    if (binder == null || !binder.isBinderAlive) return false
    val data = Parcel.obtain()
    val reply = Parcel.obtain()
    return try {
        data.writeInterfaceToken(descriptor)
        write(data)
        binder.transact(code, data, reply, 0)
        reply.readException()
        true
    } catch (e: SecurityException) {
        permissionDenied = true
        lastError = "SecurityException: ${e.message}"
        false
    } catch (t: Throwable) {
        lastError = "${t.javaClass.simpleName}: ${t.message}"
        nav = null
        vehicle = null
        false
    } finally {
        reply.recycle()
        data.recycle()
    }
}
```

```kotlin
override fun sendTbt(frame: TbtFrame): Boolean =
    transact(navBinder(), NAV_DESCRIPTOR, TX_TBT) { p ->
        p.writeByte(frame.displayType.toByte())
        p.writeInt(15)
        p.writeByte(frame.direction.toByte())
        p.writeInt(frame.distVal)
        p.writeByte(15)
        p.writeByte(frame.scale.toByte())
        p.writeByte(frame.frac.toByte())
    }

override fun sendSpeed(frame: SpeedFrame): Boolean =
    transact(navBinder(), NAV_DESCRIPTOR, TX_SPEED) { p ->
        repeat(6) { p.writeByte(0) }
        p.writeByte(1)                    // spdLimitType
        p.writeByte(0)                    // spdLimitUnit
        p.writeByte(1)                    // spdInfoType
        p.writeByte(frame.kph.toByte())
    }

override fun sendEst(frame: EstFrame): Boolean =
    transact(navBinder(), NAV_DESCRIPTOR, TX_EST) { p ->
        p.writeByte(frame.distF.toByte())
        p.writeByte(frame.unit.toByte())
        p.writeByte(frame.hour.toByte())
        p.writeByte(frame.minute.toByte())
        p.writeByte(0)                    // azimuth
        p.writeInt(frame.distI)
        p.writeByte(1)                    // estimTimeFormat
        p.writeByte(frame.timeType.toByte())
        p.writeByte(0)                    // estPointType
    }

override fun sendText(frame: TextFrame): Boolean =
    transact(vehicleBinder(), VEHICLE_DESCRIPTOR, TX_INFO) { p ->
        p.writeByte(6)
        p.writeString(frame.text)
    }
```

### 2.5 `ClusterMapper`

```kotlin
object ClusterMapper {

    fun toFrame(navi: NaviState, nowMs: Long, etaMode: Int): ClusterFrame {
        val tbt = formatTbt(navi.tbtTurnType, navi.tbtDistance)
        val speed = SpeedFrame(
            if (navi.roadSpeedLimit > 0) navi.roadSpeedLimit else navi.cameraSpeedLimit
        )
        val est = formatEstimate(navi.routeRemainDistance, navi.routeRemainTime, nowMs, etaMode)
        val text = buildText(navi)
        return ClusterFrame(tbt, speed, est, text)
    }

    fun formatTbt(icon: Int, meters: Int): TbtFrame {
        val displayType = mapTurnType(icon)
        val d = formatDistance(meters)
        return TbtFrame(displayType, 0, d.distVal, d.scale, d.frac)
    }

    fun mapTurnType(icon: Int): Int = when (icon) {
        2, 10, 18, 19 -> 65
        3 -> 70
        4 -> 67
        5, 16 -> 71
        6 -> 66
        7 -> 69
        8 -> 68
        9 -> 72
        else -> 255
    }

    data class Distance(val distVal: Int, val scale: Int, val frac: Int)

    fun formatDistance(meters: Int): Distance = when {
        meters >= 100_000 -> Distance(meters / 1000, 1, 0)
        meters >= 1_000 -> {
            val r = meters + 50
            Distance(r / 1000, 1, (r / 100) % 10)
        }
        else -> Distance(meters, 0, 0)
    }

    fun formatEstimate(
        meters: Int,
        seconds: Int,
        nowMs: Long,
        etaMode: Int
    ): EstFrame {
        val d = formatDistance(meters)
        val total = seconds.coerceAtLeast(0)
        val hour: Int
        val minute: Int
        val timeType: Int
        if (etaMode == 1) {
            val cal = java.util.Calendar.getInstance()
            cal.timeInMillis = nowMs + total * 1000L
            hour = cal.get(java.util.Calendar.HOUR_OF_DAY)
            minute = cal.get(java.util.Calendar.MINUTE)
            timeType = 1
        } else {
            hour = total / 3600
            minute = (total % 3600) / 60
            timeType = 2
        }
        return EstFrame(d.frac, d.scale, hour, minute, d.distVal, timeType)
    }

    fun buildText(navi: NaviState): String {
        val road = (navi.nextRoadName.ifBlank { navi.currentRoadName }).take(24)
        val prefix = when (navi.trafficLightStatus) {
            1 -> "[红灯 ${navi.trafficLightSeconds}s] "
            2, 4 -> "[绿灯 ${navi.trafficLightSeconds}s] "
            3 -> "[黄灯 ${navi.trafficLightSeconds}s] "
            else -> ""
        }
        if (navi.trafficLightSeconds < 0 || navi.trafficLightStatus == 0) return road
        return (prefix + road).take(24)
    }

    fun clampSpeed(prev: Int, next: Int, elapsedMs: Long): Int {
        if (next <= 0) return 0
        val target = next.coerceIn(20, 150)
        if (prev <= 0) return target
        val maxDelta = ((elapsedMs / 1000.0) * 20).toInt().coerceAtLeast(1)
        val base = prev.coerceIn(20, 150)
        return (base + (target - base).coerceIn(-maxDelta, maxDelta)).coerceIn(20, 150)
    }
}
```

### 2.6 `ClusterPublisher`

#### 2.6.1 设计要点

- **纯逻辑**：不持有 `Context`、不启动线程，`tick(now)` 可由测试直接调用。
- **最新值**：`onNaviState` 只写 `@Volatile latestNavi` 和 `lastNavAt`。
- **节流**：每通道独立记录上次发送值与时间。
- **交还**：`release()` 同步执行 3 → 8 → 清文本 → 清限速 → 清行程。
- **状态**：`StateFlow<ClusterStatus>` 供 UI 读取。

#### 2.6.2 代码骨架

```kotlin
class ClusterPublisher(
    private val transport: ClusterTransport,
    private val settings: ClusterSettings,
    private val clock: () -> Long = System::currentTimeMillis
) {
    private val _status = MutableStateFlow(ClusterStatus())
    val status: StateFlow<ClusterStatus> = _status

    @Volatile private var latestNavi = NaviState()
    @Volatile private var lastNavAt = 0L

    private var state = ClusterState.RELEASED
    private var lastTbt: TbtFrame? = null
    private var lastSpeed: SpeedFrame? = null
    private var lastEst: EstFrame? = null
    private var lastText: TextFrame? = null
    private var lastTbtAt = 0L
    private var lastSpeedAt = 0L
    private var lastEstAt = 0L
    private var lastTextAt = 0L
    private var lastSentSpeed = 0

    fun onNaviState(navi: NaviState) {
        latestNavi = navi
        lastNavAt = clock()
    }

    fun tick(now: Long = clock()) {
        if (!settings.enabled) {
            if (state != ClusterState.RELEASED) release(now)
            return
        }
        val navi = latestNavi
        if (!navi.navValid || now - lastNavAt > 3000L) {
            if (state != ClusterState.RELEASED) release(now)
            return
        }
        if (state != ClusterState.ACTIVE) state = ClusterState.ACTIVE

        val frame = try {
            ClusterMapper.toFrame(navi, now, settings.etaMode)
        } catch (t: Throwable) {
            updateError(t)
            return
        }
        sendTbtIfNeeded(frame.tbt, now)
        sendSpeedIfNeeded(frame.speed, now)
        sendEstIfNeeded(frame.est, now)
        sendTextIfNeeded(frame.text, now)
        publishState(now)
    }

    private fun sendTbtIfNeeded(f: TbtFrame, now: Long) {
        if (!settings.tbtEnabled) return
        val changed = f != lastTbt
        val keepalive = now - lastTbtAt >= 2000L
        if ((changed || keepalive) && now - lastTbtAt >= 500L) {
            if (transport.sendTbt(f)) {
                lastTbt = f; lastTbtAt = now
            } else updateError(null)
        }
    }

    private fun sendSpeedIfNeeded(f: SpeedFrame, now: Long) {
        if (!settings.speedEnabled) return
        if (now - lastSpeedAt < 1000L) return
        val clamped = ClusterMapper.clampSpeed(lastSentSpeed, f.kph, now - lastSpeedAt)
        if (clamped == lastSentSpeed && lastSpeed != null) return
        if (transport.sendSpeed(SpeedFrame(clamped))) {
            lastSpeed = SpeedFrame(clamped)
            lastSentSpeed = clamped
            lastSpeedAt = now
        } else updateError(null)
    }

    private fun sendEstIfNeeded(f: EstFrame, now: Long) {
        if (!settings.estEnabled) return
        val changed = f != lastEst
        val keepalive = now - lastEstAt >= 10_000L
        if ((changed || keepalive) && now - lastEstAt >= 1_000L) {
            if (transport.sendEst(f)) { lastEst = f; lastEstAt = now }
        }
    }

    private fun sendTextIfNeeded(f: TextFrame, now: Long) {
        if (!settings.textEnabled) return
        val changed = f != lastText
        if (changed && now - lastTextAt >= 1_000L) {
            if (transport.sendText(f)) { lastText = f; lastTextAt = now }
        }
    }

    fun release(now: Long = clock()) {
        state = ClusterState.RELEASING
        transport.sendTbt(TbtFrame(3, 0, 0, 0, 0))
        transport.sendTbt(TbtFrame(8, 0, 0, 0, 0))
        transport.sendSpeed(SpeedFrame(0))
        transport.sendEst(EstFrame(0, 0, 0, 0, 0, 1))
        transport.sendText(TextFrame(""))
        state = ClusterState.RELEASED
        lastTbt = null; lastSpeed = null; lastEst = null; lastText = null
        lastSentSpeed = 0
        publishState(now)
    }

    fun sendTestFrame(now: Long = clock()) {
        transport.sendTbt(TbtFrame(65, 0, 1, 1, 5))   // 直行 1.5km
        transport.sendSpeed(SpeedFrame(80))
        transport.sendEst(EstFrame(5, 1, 0, 30, 1, 2))
        transport.sendText(TextFrame("测试路名"))
        publishState(now)
    }
}
```

> 说明：`sendSpeedIfNeeded` 首次发送时 `lastSpeed == null`，即使值相同也要发一次；
> `lastSpeedAt == 0` 时 `now - 0` 很大，满足 1s 条件。

### 2.8 `ClusterRuntime`

```kotlin
class ClusterRuntime(
    private val transport: ClusterTransport,
    private val settings: ClusterSettings
) {
    private val publisher = ClusterPublisher(transport, settings)
    private val scheduler = Executors.newSingleThreadScheduledExecutor { r ->
        Thread(r, "cluster-tick").apply { isDaemon = true }
    }
    private var collectJob: Job? = null

    fun start(scope: CoroutineScope, flow: StateFlow<NaviState>) {
        scheduler.scheduleAtFixedRate({
            try { publisher.tick() } catch (_: Throwable) { }
        }, 0L, 100L, TimeUnit.MILLISECONDS)

        collectJob = scope.launch {
            flow.collect { publisher.onNaviState(it) }
        }
    }

    fun stop() {
        collectJob?.cancel()
        collectJob = null
        scheduler.shutdownNow()
        try {
            scheduler.awaitTermination(200L, TimeUnit.MILLISECONDS)
        } catch (_: InterruptedException) {
            Thread.currentThread().interrupt()
        }
        publisher.release()
        transport.close()
    }

    fun status(): StateFlow<ClusterStatus> = publisher.status
    fun sendTestFrame() = publisher.sendTestFrame()
}
```

## 3. 关键时序

### 3.1 启动

```
KeepAliveService.onCreate
  → RelayEngine.start
      → 注册高德广播
      → 启动 UDP/发现
      → ClusterRuntime.start
          → 启动 cluster-tick
          → 收集 naviStateFlow
```

### 3.2 导航更新

```
高德发 10001
  → Decoder.onReceive（主线程）
  → NaviState.copy(navValid=true, tbt..., route...)
  → RelayEngine 收集 → ClusterRuntime.onNaviState
  → 下个 tick（≤100ms）
      → Mapper.toFrame
      → TBT 变化/保活 → sendTbt
      → 限速变化 → clamp → sendSpeed
      → 行程变化/10s → sendEst
      → 文本变化 → sendText
```

### 3.3 退出导航

```
高德发 EXTRA_STATE=9（或 3s 无广播）
  → Decoder navValid=false
  → 下个 tick
      → Publisher.release
          → TBT 3（结束）
          → TBT 8（罗盘）
          → Speed 0
          → Est 0
          → Text ""
```

### 3.4 开关切换

```
用户关闭 cluster_enable
  → 下个 tick
      → Publisher.release
      → 后续 tick 直接 return
用户打开
  → 等待 navValid
  → 第一个有效帧 → ACTIVE
```

## 6. 风险与验证点

| 风险 | 验证 | 处理 |
|---|---|---|
| 普通应用写 `INavigation` 被拒 | 实车 `probe()` | 状态页显示 `PermissionDenied`；L1 不成立则走系统签名 |
| 高德字段名/单位不一致 | logcat 打印 10001 extras | 按实际字段调整 Decoder |
| 高德红绿灯不在 10001 | 抓包 | 只在 10019/10020 读 |
| 百度 ADAS 同时写 | 实车双开 | UI 警告；L2 做仲裁 |
| 仪表停在旧帧 | 退出导航 | 交还序列 3→8→清文本 |
| 系统 OTA 重置 | OTA 后 | 重做配置 |
| 不启动 ADAS 时天气不更新 | 车机天气组件 | DuerOS 天气依赖 ADAS 的 `NAVI_GPS_CHANGED` 提供经纬度；加定位桥或启用 DuerOS 自带定位 |
| ETA 模式不匹配 | 实车 | 切换 `cluster_eta_mode` 1/2 |
