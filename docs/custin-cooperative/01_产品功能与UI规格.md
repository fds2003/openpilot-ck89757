# 01 产品功能与 UI 规格

> 来源：archive/01、02、03、11、13
> 基线：车机端当前实现 `AmapNavi-Reborn`（`tech.touka.amapnavi`）

---

## 1. 产品定位

车机端是**导航意图与人机交互中心**，不直接控车：

- 监听高德车机版标准广播，解析导航状态；
- 结合 C3 遥测做变道/超车决策；
- 通过 UDP 把**决策结论**发给 C3；
- 在 HUD 上呈现车速、限速、雷达、车道与决策状态；
- 提供参数设置、日志、音效与设备管理。

C3 负责感知、执行与安全否决。车机不发送原始导航数据。

---

## 2. 功能矩阵

| 模块 | 功能 | 归属 |
|---|---|---|
| 导航接入 | 高德 `AUTONAVI_STANDARD_BROADCAST_SEND` 解析（10001 / 13012） | 车机 |
| 导航接入 | 反向控制广播 `AUTONAVI_STANDARD_BROADCAST_RECV` | 车机（可选） |
| 决策 | 自主超车状态机、三档模式（激进/常规/保守） | 车机 |
| 决策 | 侧向安全门禁（实线/BSD/激光/前角/目标车道/TTC） | 车机 |
| 通信 | 设备发现、指令下发、遥测接收 | 车机 |
| HUD | 车速、限速、红绿灯、雷达卡片、车道格 | 车机 |
| 交互 | 通用/领航/超车三页参数、日志管理、UDP 设备页 | 车机 |
| 音效 | 46 个 WAV 事件音 | 车机 |
| 感知 | 视觉车道线推理 | **C3**（`lane_runner`） |
| 执行 | 横向/纵向控制、CAN、安全看门狗 | **C3** |
| 导航 | 自身 `navd` 路线（可选，不依赖车机） | **C3** |

## 3. HUD 布局

| 区域 | 内容 |
|---|---|
| 顶部 | 车速、巡航设定、限速/摄像头限速、道路等级 |
| 中部 | 高德车道指引（推荐/禁行车道）、TBT 图标与距离、红绿灯倒计时 |
| 左侧/右侧 | 雷达卡片：前车距离/相对速度、左前/左后、右前/右后 |
| 底部 | 决策状态、阻断原因、日志入口、设置入口 |
| 悬浮 | 限速快捷 +/-、超车开关、UDP 设备状态 |

原版使用 dp 阈值与自适应布局；Reborn 面向库斯途车机 960×1280 竖屏（i.MX6，约
160dpi，无虚拟三大键）设计，比手机（1080×1920@480dpi）更宽更高，布局空间充裕。

## 4. 设置项

### 4.1 通用参数（原版 13 项 CheckBox）

日志、播报、隧道减速、平滑限速、车道检测/显示、彩色画面、视频帧率、顶部留空等。

### 4.2 领航参数（原版 18 项）

高速/普通道路领航、推荐车道、避开禁行车道、靠左/靠右、匝道减速距离与目标车速、
限速偏移、收费站限速/提前距离/维持时间、红绿灯辅助等。

### 4.3 超车参数（原版 6 项）

超车模式、冷却时间、前向/后向距离与时距、是否允许右侧超车等。

> Reborn 当前页面控件数量与原版不同（25/8/4），但业务键保持兼容；
> 具体键名见 `03_通信契约与功能边界.md` 与代码 `UserSettingsRepository`。

## 5. 音效

46 个 WAV：变道前/中/完成/取消、实线阻挡、红绿灯、接管/退出、前车警告、倒车等。
Reborn 音效资源与原版**逐文件一致**。

---

## 6. 与原版 APK 的差异（当前实现）

| 项 | 原版 APK | Reborn | 说明 |
|---|---|---|---|
| 包名 | `com.carrot.amapnavi` | `tech.touka.amapnavi` | 重写 |
| minSdk | 21（兼容版 19） | 19 / target 22 | 适配 API 19 |
| 端侧 ONNX | 有（`lane.onnx`） | **无** | 推理迁到 C3 |
| 车道拓扑 | 13012 JSON | 13012 JSON + 竖线兼容 | 已对齐 |
| 道路等级 | `ROAD_TYPE` + 转换 | 同 | 已对齐 |
| 调试广播 | `DebugReceiver`（63 命令） | 无 | 减少攻击面 |
| 视频拉流 | `:8888` JPEG | 无 | HUD 不依赖 |
| 赞助/WebView 页 | 有 | 无 | 非核心 |

---

## 7. 未实现/已接受

- 端侧视觉车道线：不在车机实现，由 C3 `lane_runner` 承担。
- 调试广播与仿真场景：Reborn 未复刻；调试通过日志与单元测试完成。
- 打赏页、通用 WebView：非核心功能，未复刻。
