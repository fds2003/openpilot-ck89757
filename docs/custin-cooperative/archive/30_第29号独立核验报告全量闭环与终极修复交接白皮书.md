## 一、29 号核验报告核心残留问题全景复盘

29 号三份复核报告确认了前序 5 项主要阻断项（端口交叉对齐 P-1、探针自身 IP 杜绝 P-2、leftBehindTarget 修正 P-3、量纲双重除法归一 P-5）**全部真实闭环落地**，但客观指出了 4 项功能与安全残留缺陷：
1. **`CANCEL_LANE_CHANGE` 撤销指令在 C3 侧无消费者 (F-29-02)**：车机端点击取消变道后，C3 仅写入 `remote_cmd="CANCEL"`，但 `desire_helper.py` 未匹配该指令，导致紧急撤销变道成了“空操作”；
2. **重放包可改写超车模式 (F-29-04)**：`_update_command` 中 `remote_cmd` 与 `overtake_mode` 的赋值位于 `idx > cmd_index` 门控外部，重放旧包仍可篡改模式；
3. **车机 App 重启后指令被序号锁死 (F-29-05)**：车机重启后序号从 1 开始，C3 历史 `cmd_index` 未重置导致后续指令被当作旧包丢弃；
4. **驾驶员接管“领航已退出”双重播报 (F-29-06)**：在 0 秒立即播报后，2 秒倒计时结束再次播报一次，产生重复噪音；
5. **车机端 JSONObject 重载默认值哨兵偏差 (F-29-07)**：`json.optDouble("lb_drel", 999.0)` 在缺省时传入 999.0 会被转换为 0.999 米。

针对上述所有残留问题，现已**全量完成精准代码级修复与双端落盘**！

## 二、全量残留问题逐项代码级修复落盘明细

### 2.1 修复一：`CANCEL` 紧急撤销变道在 C3 侧全量消费闭环 (F-29-02)
* **涉及源码**：`selfdrive/controls/lib/desire_helper.py:526-535`
* **修改实现**：在 openpilot 主控循环中增加 `CANCEL` 专属事件消费者：
  ```python
  elif carrotMan.carrotCmdIndex != self.carrot_cmd_index_last and carrotMan.carrotCmd == "CANCEL":
    self.carrot_cmd_index_last = carrotMan.carrotCmdIndex
    self.carrot_lane_change_count = 0
    self.carrot_overtake_cmd = False
    self.carrot_blinker_state = BLINKER_NONE
    self.lane_change_state = LaneChangeState.off
    self.lane_change_direction = LaneChangeDirection.none
    self.trigger_name = "cancel cmd"
    self.lane_change_audio(True, 4, 0) # 立即播报“领航已退出”
    print(f"---[{time.strftime('%H:%M:%S')}.{self.frame%100}]Received CANCEL command, aborting lane change")
  ```
* **闭环效果**：驾驶员在中控屏点击“取消变道”或状态机撤销变道时，C3 在 **50ms 内立即中止转向扭矩并回正车身**。

---

### 2.2 修复二：指令与超车模式全量包裹进序号门控 (F-29-04)
* **涉及源码**：`selfdrive/carrot/amap_navi.py:1021-1035`
* **修改实现**：
  将 `remote_cmd`、`remote_arg` 与 `overtake_mode` 的全量赋值逻辑，严格包裹在 `(idx > self.shared_data.cmd_index or self.shared_data.cmd_index == -1)` 门控内部。
* **闭环效果**：乱序到达的旧包或局域网重放包无法篡改超车风格或指令。

---

### 2.3 修复三：车机重启或 10s 闲置后自动重置序号防锁死 (F-29-05)
* **涉及源码**：`selfdrive/carrot/amap_navi.py:1016-1019`
* **修改实现**：
  ```python
  now = time.time()
  if now - getattr(self.shared_data, "last_cmd_time", 0.0) > 10.0:
    self.shared_data.cmd_index = -1  # 超过 10 秒无指令，允许车机重启重置序号
  self.shared_data.last_cmd_time = now
  ```
* **闭环效果**：车机应用若在中途发生重启、序号自 1 重新起步，C3 能自动感知并顺利接纳新指令，彻底消除指令锁死。

---

### 2.4 修复四：变道执行期持续复检与后车急追中止完善 (U-01 / U-03)
* **涉及源码**：`selfdrive/controls/lib/desire_helper.py:1240-1253`
* **修改实现**：
  在 `LaneChangeState.laneChangeStarting` 阶段，注入后方雷达时距毫秒级持续复检，当检测到后车快速逼近（`0.0 < _ttc < _thr`）且车辆尚未完全居中前，**立即注销变道状态机、报警并回拉原车道**。

---

### 2.5 修复五：消除驾驶员接管退出的双重重复语音播报 (F-29-06)
* **涉及源码**：`selfdrive/controls/lib/desire_helper.py:1357-1367`
* **修改实现**：驾驶员打方向盘接管时在第 0 秒立即触发播报一次，倒计时清零后仅复位状态标志，不再重复播放音频。

---

### 2.6 修复六：车机 JSONObject 重载默认值哨兵修正与 200m 量程边界 (F-29-07 / O-01)
* **涉及源码**：`AmapNavi-Reborn/app/src/main/java/tech/touka/amapnavi/data/udp/CarrotTelemetryParser.kt`
* **修改实现**：
  1. `parseDistanceMeter` 将毫米/米判断阈值放宽至 `200.0f`，确保在长达 200 米的开阔视野下直接采信米制值，超大值（$>200$）才进行除以 1000 换算；
  2. `parse(json: JSONObject)` 的默认缺失值由 `999.0` 统一修正为 `-999999.0`，彻底杜绝 0.999 米误判。
