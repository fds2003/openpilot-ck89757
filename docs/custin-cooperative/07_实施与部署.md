## 1. 车机端

### 1.1 构建

```bash
cd AmapNavi-Reborn
./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

- minSdk 19 / target 22 / `armeabi-v7a`。
- 构建前确认 `local.properties` 的 `sdk.dir` 有效。

### 1.2 安装后检查

```bash
adb shell dumpsys package tech.touka.amapnavi | grep -E "versionName|versionCode"
adb logcat -s AmapNavi:* | head
```

- 确认已获得网络/存储权限（target 22 安装即授予）。
- 打开 App，确认前台保活服务启动。

## 2. C3 端

### 2.1 代码与依赖

```bash
ssh comma@<C3_IP>
cd /data/openpilot
git rev-parse --short HEAD
pip install -r selfdrive/carrot/requirements_lane.txt
python -c "import onnxruntime; print(onnxruntime.__version__)"
ls -lh selfdrive/carrot/models/lane.onnx
```

- `onnxruntime` 未安装时 `lane_runner` 会打印原因并退出，不会崩溃重启。
- aarch64 wheel 需 glibc ≥ 2.28；不满足时选低版本或自行构建。

### 2.2 进程与服务

`system/manager/process_config.py` 应包含：

```python
PythonProcess("carrot_man", "selfdrive.carrot.carrot_man", always_run)
PythonProcess("lane", "selfdrive.carrot.lane", only_onroad)
PythonProcess("lane_runner", "selfdrive.carrot.lane_runner", only_onroad)
# amap_navi 保持注释
```

重启后检查：

```bash
pgrep -af 'carrot_man|lane_runner|selfdrive.carrot.lane'
ss -ulnp | grep -E ':(4210|4211|4213|4215|7705|7706)\b'
```

- 每个端口只能有一个 owner。
- 7710/7709/12345 必须仍是 `127.0.0.1`。

### 2.3 参数

```bash
python - <<'EOF'
from openpilot.common.params import Params
p = Params()
for k in ("CarrotCooperativeMode", "CarrotUdpAllowedIps", "IsOnroad"):
    print(k, "=", p.get(k))
EOF
```

| 参数 | 建议 |
|---|---|
| `CarrotCooperativeMode` | `1`（车机意图优先） |
| `CarrotUdpAllowedIps` | 同网段留空；跨网段填车机 IP，逗号分隔 |
| `CARROT_BIND_HOST`（env） | 默认 `0.0.0.0`；仅本机调试设 `127.0.0.1` |

### 2.4 安装器（可选）

C3 首次部署可用自定义安装器（见 archive/INSTALLER_GUIDE.md）：
将仓库/分支写入安装器 ELF，设备初始化时自动拉取。

## 3. 网络

- 车内热点建议 WPA2，必要时开启 AP 隔离。
- 车机与 C3 必须同网段，或配置 `CarrotUdpAllowedIps`。
- C3 管理 Web 仅 loopback，通过 SSH 隧道访问：

```bash
ssh -L 8088:127.0.0.1:8088 comma@<C3_IP>
```

---

## 4. 首次启动顺序

1. C3 上电，确认 `carrot_man` 起来。
2. 车机连同一热点，打开 App。
3. 设备页应发现 C3（5510/4210）。
4. 确认 7706 遥测到达车机（HUD 车速）。
5. 确认 7705 指令能到 C3（抓包或日志）。
6. onroad 后确认 4213 车道数据与 4215 红绿灯（如使用 adbridge）。

## 5. 一键更新

```bash
cd /data/openpilot
./selfdrive/carrot/scripts/c3_update.sh
```

脚本依次执行：工作区检查 → fetch/reset 到 `cp-custo-amap` → chown →
安装 `requirements_lane.txt` → 校验 `lane.onnx` 哈希 → Python 语法检查 →
设置 `UpdaterTargetBranch` / `CarrotCooperativeMode` → 重启 manager → 端口/日志自检。

| 参数 | 作用 |
|---|---|
| `--reboot` | 更新后整机重启 |
| `--no-restart` | 只更新，不重启 |
| `--check` | 只做健康检查 |
| `--force` | 丢弃本地改动 |
| `--clean` | 额外 `git clean -xdff`（会删未跟踪文件） |

> 默认不清理未跟踪文件；需要时显式加 `--clean`。

## 7. 常见问题

| 现象 | 排查 |
|---|---|
| 车机发现不了 C3 | 4210 绑定/防火墙/热点隔离；`ss -ulnp` |
| 遥测不到 | 7706 方向、client 是否登记、白名单拒绝日志 |
| 指令无效 | 7705 报文、`carrotCmd` 是否出现在 rlog、序号是否单调 |
| `lane_runner disabled` | onnxruntime/模型路径 |
| 车道类型为 0 | `lane_runner` 是否在跑、4213 是否到达、C3 是否收到 |
| 红绿灯不更新 | 4215 报文、`DETECT` 是否活跃、3s 过期 |
| 双端都变道 | 协同模式是否开启、车机是否在线 |
