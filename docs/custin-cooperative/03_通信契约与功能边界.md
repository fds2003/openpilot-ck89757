## 1. 端口与方向

| 端口 | 方向 | 绑定 | 载荷 |
|---|---|---|---|
| 4210 | 车机 → 广播 | C3 接收 | `{"cmd":"discover","port":5510}` |
| 5510 | 车机本地 | 车机绑定 | C3 `c3_pong` 响应 |
| 7705 | 车机 → C3 | C3 接收 | `cmd` 控制指令 |
| 7706 | C3 → 车机 | 车机绑定 | 遥测 JSON（10–20Hz） |
| 4211 | 车机 → C3 | C3 接收 | 转向灯 `ctrl` / 传感器上行 |
| 4213 | C3 本地 / 车机 → C3 | C3 接收 | `resp:"lane"` 车道类型 |
| 4215 | adbridge → C3 | C3 接收 | 红绿灯 `tl/cd/st/dir` |
| 5210 / 4212 | — | **未使用** | 仅常量声明 |

> C3 接收端由 `CARROT_BIND_HOST` 控制（默认 `0.0.0.0`）；
> ZMQ 7710、路由 7709、Kisa 12345 保持 loopback。

## 2. 车机 → C3 指令（7705）

```json
{"cmd":"LANECHANGE","direction":"LEFT","arg":"LEFT","param":1,
 "seq":12,"index":12,"v_cruise":115,"blinker":1,"timestamp":1730473200123}
```

| 字段 | 说明 |
|---|---|
| `cmd` | `LANECHANGE` / `SPEED_LIMIT` / `CANCEL_LANE_CHANGE` |
| `direction` / `arg` | `LEFT` / `RIGHT` / `KEEP` |
| `param` | 0=激进、1=常规、2=保守 |
| `seq` / `index` | 单调自增，C3 防重放 |
| `v_cruise` | 目标车速（`SPEED_LIMIT` 时生效） |
| `blinker` | 1 左、2 右、0 关 |

> 原版 APK 走 7706 的 `{"carrotIndex","carrotCmd":"LANECHANGE","carrotArg"}`；
> 两代协议不可混用。

## 3. C3 → 车机遥测（7706）

关键字段（完整约 42 键）：

| 分组 | 字段 |
|---|---|
| 自车 | `IsOnroad`, `v_ego_kph`, `v_cruise_kph`, `active`, `engaged`, `steer_angle`, `gas_press`, `brake_press` |
| 前车 | `lead1`, `drel`, `vrel`, `vlead`, `lead_accel` |
| 侧向 | `l_lead/l_drel/l_vrel`, `r_lead/r_drel/r_vrel` |
| 盲区 | `left_blindspot`, `right_blindspot`, `l_front_blind`, `r_front_blind`, `blind_enable` |
| 激光 | `lidar_*_vdist_time`, `lidar_*_vrel_time`, `lidar_l/rblind`, `lidar_lf/lb/rf/rbblind` |
| 车道 | `lane_width`, `l/r_lane_width`, `l/r_edge_dist` |
| 状态 | `atc_state`, `roadcate`, `op_blocked`, `road_blocked` |

车机解析其中安全相关子集（25 项），其余按需扩展。

## 4. 车道类型（4213）

```json
{"resp":"lane","port":4212,"left_lane":1,"right_lane":0,
 "lane_valid":1,"sup_lidar_l":0,"sup_lidar_r":0}
```

- `0` 实线/禁行，`1` 虚线。
- 来源：C3 `lane_runner`（VisionIPC + `lane.onnx`）。
- C3 `_lane_recv_thread` 消费后写 `shared_data.left_lane/right_lane`。

---

## 5. 转向灯（4211）

```json
{"ctrlid":12,"ctrl":"blinker","state":"left"}
```

- `state`：`left` / `right` / 其它（关闭）。
- 原版 APK 使用该通道；Reborn 也把 `blinker` 随 7705 指令携带。

---

## 6. 红绿灯（4215）

```json
{"tl":"red","cd":18,"st":1,"dir":"left","src":"adbridge"}
```

- `tl`：`red` / `green`。
- C3 映射为 `traffic_state`（1 红 / 2 绿 / 0 无）。
- `DETECT` 指令优先；4215 数据 3s 过期清零。

## 7. 高德广播契约

### 7.1 KEY_TYPE

| KEY_TYPE | 内容 |
|---|---|
| 10001 | 导航/限速/测速/TBT/红绿灯 |
| 13012 | `EXTRA_DRIVE_WAY` 车道拓扑（JSON） |
| 10019 / 10020 | **原版 APK 不使用** |

### 7.2 道路等级

```
ROAD_TYPE → roadcate_conv：0→1、6→0、1→2、其它→8
isHighway = (roadcate == 0 || roadcate == 1)
```

### 7.3 车道拓扑（13012）

```json
{"drive_way_enabled":true,"drive_way_size":3,
 "drive_way_info":[
   {"drive_way_lane_Back_icon":"15","trafficLaneAdvised":false},
   {"drive_way_lane_Back_icon":"18","trafficLaneAdvised":true},
   {"drive_way_lane_Back_icon":"32","trafficLaneAdvised":false}]}
```

- `drive_way_lane_Back_icon < 15` → 禁行（X）。
- `trafficLaneAdvised=true` → 推荐车道。

### 7.4 红绿灯（10001 包内）

`TRAFFIC_LIGHT_NUM` / `trafficLightStatus` / `redLightCountDownSeconds`。

## 8. 功能边界

| 能力 | 车机 | C3 |
|---|---|---|
| 高德广播解析 | ✅ | ❌ |
| 导航意图/变道决策 | ✅ | 仅安全否决 |
| 侧向安全门禁 | ✅ | ✅（独立） |
| 车道线视觉 | ❌ | ✅ `lane_runner` |
| 横向/纵向执行 | ❌ | ✅ |
| HUD/音效/设置 | ✅ | ❌ |
| 协同模式开关 | 参数 | 执行 |

原则：**车机出意图，C3 执行并可否决；C3 不猜导航意图。**
