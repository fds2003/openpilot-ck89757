## 1. 进程模型

`system/manager/process_config.py`：

```python
PythonProcess("carrot_man", "selfdrive.carrot.carrot_man", always_run)
#PythonProcess("amap_navi", ...)   # 已注释，避免双实例端口竞争
PythonProcess("lane", "selfdrive.carrot.lane", only_onroad)
PythonProcess("lane_runner", "selfdrive.carrot.lane_runner", only_onroad)
```

- `carrot_man` 是唯一常驻进程，内嵌 `AmapNaviServ`。
- **禁止**再启动独立 `amap_navi`：会双发布者 + 端口竞争。
- `lane_runner` 是独立进程，但不发布 `amapNavi`。

## 2. UDP 线程

| 线程 | 端口 | 职责 |
|---|---|---|
| `_discovery_responder_thread` | 4210 | 发现探针，登记 client（device=navi） |
| `_udp_recv_thread` | 4211 | 收车机/外设上行；`_process_single_packet` |
| `_lane_recv_thread` | 4213 | 收 `resp:"lane"` |
| `_traffic_light_recv_thread` | 4215 | 收 adbridge 红绿灯 |
| `_headunit_cmd_recv_thread` | 7705 | 收 Reborn `cmd` |
| `_data_deal_thread` | 发 7706 | 向 clients 推遥测 |
| `carrot_man_thread` | 7706 | 收原版 `carrotCmd` |

绑定地址由 `CARROT_BIND_HOST` 控制（默认 `0.0.0.0`）。

## 3. 命令链

```
7705 cmd ─► amap_navi.remote_cmd ─► carrot_man.get_data_amap_navi()
7706 carrotCmd ─► carrot_serv.update(json)
                     ▼
              carrot_serv.carrotCmd/Arg
                     ▼ carrotMan (cereal)
              desire_helper.py:506  LANECHANGE / OVERTAKE
              desire_helper.py:526  CANCEL
              desire_helper.py:956  overtake_mode → TTC 1.8/2.5/3.5s
```

- `carrot_serv.command_handlers` 只处理 `DETECT` 与 `SPEED_LIMIT`；
  变道由 `desire_helper` 直接消费 `carrotCmd`。
- `index/seq` 单调递增；10s 无指令允许重置。

## 4. ATC 与协同模式

`carrot_serv.update_auto_turn()`：

- 正常：根据 `navInstruction` 的 TBT 生成 `atc_type` 与速度规划；
- 协同模式 + 车机在线：**只把 `atc_type` 置为 `none`**，保留 `atc_desired` 速度规划；
- 车机失联（`app_ip_ts` 超 15s）：恢复自主 ATC。

> 注意：`atc_desired` 是限速值（250=无限制），不是布尔；不能早退成 0。

参数：`CarrotCooperativeMode`（默认 true，8088 白名单可写）。

## 5. 车道推理 `lane_runner`

```
VisionIPC(camerad) → NV12 → RGB 416
  → lane.onnx（output0 [1,42,3549] / output1 [1,32,104,104]）
  → decode（conf 0.25、NMS 0.5、32 系数 × 104² 掩膜）
  → selectLanes（底部行、左右分区、最近中心）
  → UDP 127.0.0.1:4213
  → amap_navi._lane_recv_thread → left_lane/right_lane
```

- 模型：`selfdrive/carrot/models/lane.onnx`（来自原版 APK，13.2MB）。
- 依赖：`requirements_lane.txt`（`onnxruntime ≥ 1.18`）。
- 20Hz；缺依赖/模型时 `check_runtime()` 打印原因并退出，避免重启刷屏。

## 6. 红绿灯

adbridge 4215 → `_traffic_light_recv_thread` → `shared_data.traffic_state`：

- `DETECT` 活跃（`traffic_light_count > 0`）时优先；
- 否则采用 4215，3s 过期清零；
- 同样经过源信任检查。

---

## 7. Cereal 与单一发布者

- `amapNavi` 由 `carrot_man` 内嵌实例发布，字段含 `leftLine/rightLine/overtakeMode/...`。
- `carrotMan` 由 `carrot_serv` 发布，`desire_helper` 消费。
- 任何新进程（含 `lane_runner`）**不得** `PubMaster(['amapNavi'])`。

---

## 8. 参数与开关

| 参数 | 默认 | 作用 |
|---|---|---|
| `CARROT_BIND_HOST`（env） | `0.0.0.0` | 接收绑定地址 |
| `CarrotCooperativeMode` | true | 车机意图优先 |
| `CarrotUdpAllowedIps` | 空 | 显式白名单（严格模式） |
| `LANE_MODEL_PATH`（env） | `/data/openpilot/selfdrive/carrot/models/lane.onnx` | 模型路径 |

## 9. 已知约束

- `onnxruntime` 的 aarch64 wheel 为 manylinux_2_28（glibc ≥ 2.28）。
- 20Hz 推理在 C3 上需实测；OpenCL provider 不可用时回退 CPU。
- 协同模式只抑制导航 ATC；驾驶员打灯变道不受影响。
- 两代协议并存，遥测只发 7706。
